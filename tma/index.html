Subdom — создать NFT субдомен .ton

Инструмент для создания независимых NFT-субдоменов в сети TON. Домен принадлежит вам, а не платформе.

  • Добавить Subdom Zone — создать коллекцию субдоменов (SBT или Proxy)
  • Создать субдомен — добавить субдомен в коллекцию
  • Блокчейн-Профиль — цифровая идентичность и функционал для доменов, субдоменов .ton и юзернеймов @ в Telegram. Загрузи аватар, категорию, описание прямо в txt записи домена
  • Управление DNS записями — привязать кошелёк, сайт, хранилище для любого субдомена
  • Создать торрент — загрузите файлы, выберите провайдера TON Storage, получите bagID
  • Рынок — продайте субдомен, прокси-домен или сделайте оффер

Subdom — Create an NFT Subdomain on .ton

A tool for creating independent NFT subdomains on the TON network. The domain belongs to you, not the platform.

  • Add a Subdom Zone — create an SBT or Proxy subdomain collection
  • Create a Subdomain — add a subdomain to a collection
  • Blockchain Profile — digital identity and functionality for .ton domains, subdomains, and Telegram @usernames. Upload an avatar, category and description straight into the domain's txt records
  • Manage DNS Records — link a wallet, site, or storage to any subdomain
  • Create a Torrent — upload files, pick a TON Storage provider, get a bagID
  • Market — sell a subdomain, proxy domain, or make an offer
